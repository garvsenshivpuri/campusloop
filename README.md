# CampusLoop

A responsive, front-end student marketplace demo. Students can browse sample second-hand listings, search and filter categories, save items, view listing details, contact sellers by email, and post a listing.

## Run locally
1. Extract the project folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. No build step or package installation is required.

## Features
- Responsive dark premium UI with lime accent, gradients, motion and mobile layout
- Search and category filters
- Listing detail modal
- Save/favourite listings
- Create listing form
- Local browser persistence using `localStorage`
- Seller contact via email link
- No payment or checkout functionality

## Important demo limitations
This is a front-end prototype. New listings and saved items are stored only in the current browser on the current device. Other students will not see them. Student authentication, shared database, image uploads, moderation, reporting and production deployment configuration are not connected. Use a backend such as Supabase or Firebase before launching as a real multi-user campus marketplace.

## Safety
Meet in a public campus location, inspect an item before agreeing to buy, and avoid sharing sensitive personal information. CampusLoop does not handle payments.
